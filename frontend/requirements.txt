# ------------------------------------------------------------------------------
# System & Runtime Prerequisites:
# ------------------------------------------------------------------------------
# - Node.js: >= 18.0.0 (LTS recommended)
# - npm: >= 9.0.0
#
# ------------------------------------------------------------------------------
# Installation Instructions:
# ------------------------------------------------------------------------------
# 1. Open terminal in the frontend directory:
#      cd frontend
# 2. Install all dependencies:
#      npm install
# 3. Start development server:
#      npm run dev
# 4. Build for production:
#      npm run build
#
